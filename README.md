## About this project

This repository contains the personal portfolio of **Nassreddine El Makhlouq**, a Morocco-based web developer with a practical background in electronics and educational robotics.

The design is a lightweight editorial interface with a **warm light theme, a dark-mode option, subtle green accents and responsive layouts**. It is built without a front-end framework or a build step.

### Features

- **Bilingual interface** — English and Arabic, including right-to-left layout.
- **Responsive design** — built for desktop, tablet and mobile.
- **Theme switching** — light and dark appearances; preference remembered locally.
- **Project showcase** — five featured examples and working category filters.
- **Accessibility** — keyboard-friendly navigation, clear focus styles and reduced-motion support.
- **SEO essentials** — descriptive titles, metadata, canonical links, sitemap and structured data.
- **Lightweight assets** — no external framework or font downloads required.
- **Contact shortcuts** — email, GitHub, LinkedIn and Telegram.

## Run locally

No package installation required. Clone this repository, then open `index.html` in a browser.

```bash
git clone https://github.com/NASSREDDINE-net/EL-MAKHLOUQ-NASSREDDINE.git
cd EL-MAKHLOUQ-NASSREDDINE
python -m http.server 8000
```

Visit `http://localhost:8000`. A local server is recommended for realistic development and routing tests.
