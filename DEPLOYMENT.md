# Publish the Portfolio via GitHub Pages

This repository contains the Nassreddine El Makhlouq portfolio (Arabic / English, dark / light).

1. Open **Settings > Pages** on this repository.
2. Choose **Deploy from a branch**, branch **main**, folder **/(root)**.
3. Save. GitHub Pages will publish the project at **https://nassreddine-net.github.io/EL-MAKHLOUQ-NASSREDDINE/** when the build succeeds.
4. The site's canonical, sitemap, social-image and manifest paths already target that project URL.

The existing README.md and LICENSE were preserved. No custom domain (CNAME) was copied from the original repository.
